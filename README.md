## ⚡ Quick Start

### 1. Clone Repository
bash
git clone [https://github.com/username/ponta-labs.git](https://github.com/username/ponta-labs.git)
cd ponta-labs

### 2. Install Dependencies
npm install
# atau
yarn install
### 3. Environment Setup
Buat file `.env` di direktori utama:
PORT=3000
API_KEY=your_secret_api_key
### 4. Run Application
npm start

### 👤 Authentication
- `POST /api/v1/auth/register` - Daftar akun baru
- `POST /api/v1/auth/login` - Masuk & dapatkan token

### 🛠️ Core Services
- `GET /api/v1/data` - Ambil semua data utama
- `POST /api/v1/data/create` - Tambahkan data baru
